# Provenance

Original toolkit code by DUYTRUYENTHONG, adapted from the owner's Vietnamese commerce TTS and content tooling. This public package omits account state, local runtime links, private reviews, generated media and weights.

VieNeu integration calls the separately installed package rather than distributing upstream model code or voices. Gwen/Qwen are separate preparation/reference paths; no trained adapter is claimed. Reviewed upstream references and pins are documented in viet-commerce-tts/docs/REFERENCES.md. Third-party bundled dependency licenses remain in dist/licenses/.
